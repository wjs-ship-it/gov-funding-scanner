===== 3/10 — 왜 검색이 안 되는가 =====

정부 지원사업의 문제:

1. 키워드 사각지대 — 내가 지원 가능한데 제목에 내 키워드가 없음
2. 자격요건 오판 — 제목만 보고 지원했다가 "예비창업자 불가"로 탈락
3. 너무 많음 — 271건을 사람이 일일이 읽을 수 없음

그래서 AI한테 시켰다.

1) Python 크롤러가 K-Startup + 기업마당에서 모집중 공고 전부 수집 (271건, 2분)
2) AI한테 내 프로필 알려주고 전체 제목을 읽게 함
3) "너 이거 지원 가능해" → 상세공고까지 확인해서 자격요건 검증
4) 최종 보고서: 즉시 지원 / 로드맵 / 변형 가능

===== 6/10 — 핵심: "변형 지원" =====

제일 가치 높은 건 C그룹 — "변형하면 지원 가능한 것들"

예시:
- TTS 만드는 회사 → "콘텐츠 제작지원" (음성 콘텐츠니까)
- AI 헬스케어 → "사회서비스 창업지원" (장애인 접근성이니까)
- SaaS → "아트코리아랩 입주" (디자인 도구니까)

이런 건 사람이 읽어도 못 찾는다.
AI가 "이건 각도 바꾸면 너한테 해당돼"라고 알려준다.


===== 7/10 — 3분류 시스템 =====

보고서는 이렇게 나온다:

A. 즉시 지원 가능 (마감순)
→ 지금 바로 서류 넣어도 되는 것들

B. 로드맵 (트리거 명시)
→ "법인 설립하면 열림" "투자 받으면 열림"
→ 경진대회 수상 → 투자유치 → TIPS 같은 연쇄 경로

C. 변형 가능 (프레이밍 제안)
→ 아이템을 다른 분야 언어로 재서술하는 각도
